PHY TOOLS — NOVEMBER 10 2026 TEST-REPOSITORY UPDATE
==================================================

This package is intended for the TEST repository only. Do not replace the live/original site until the test site has been checked in a real browser.

WHAT WAS CORRECTED
------------------
1. Non-Boyle 3D WebGL setup
   - The generic engine previously requested an opaque WebGL context and explicitly asked for a high-performance GPU. That differed from the working Boyle's Law renderer configuration.
   - It now uses the same alpha-enabled, default GPU-selection approach as Boyle's Law.
   - If antialiasing context creation fails, it retries with antialiasing disabled.
   - The browser error panel now displays the actual error name and message instead of hiding it behind a generic warning. This gives a specific diagnostic if a browser or device still cannot create a WebGL context or load a module.

2. Energy Forms and Changes model
   - The catalogue labels this as a thermal/heat-energy experiment. It was incorrectly being rendered using the generic gas piston model.
   - It now has a dedicated calorimeter/beaker model with visible water, heater, thermometer, molecules and heat-flow indicators. Mass and temperature-change inputs affect the visual model.
   - Gas-law tools remain on the piston-and-particle model.

3. Simulator learning detail
   - The page retains the equation, live graph, calculated result, two controls, pause/reset, camera controls, fullscreen, sound, observation notes and study note.
   - Added a translated three-step "How to investigate" guide.
   - English and Sinhala strings were added for that guide and the 3D error details.

4. PHY branding on pages
   - Added/kept the PHY favicon on the home, category, simulator, admin, Boyle, About redirect and 404 pages.
   - Made the main page, category page, simulator, admin and Boyle headers sticky so the PHY logo remains visible while scrolling.
   - Added PHY TOOLS branding to Boyle's Law while leaving its inline 3D simulation module unchanged.

IMPORTANT LIMITATION
--------------------
The workspace used to prepare this package cannot resolve external CDN hosts, so it cannot download Three.js or perform a real live WebGL browser test against GitHub Pages. The code changes above are checked statically, but successful rendering on the user's browser/device must still be confirmed on the TEST repository. If a 3D model still fails, the page now shows the exact browser error in the stage. Send that text or a screenshot for the next targeted fix.

PHYSICS MODEL SCOPE
-------------------
The package contains 130 tool definitions. The tools reuse a set of topic-oriented 3D model families; this does not mean 130 separate bespoke models or all 130 physical models have been independently validated against the full A/L syllabus. The displayed equations/assumptions should still be reviewed topic by topic.
