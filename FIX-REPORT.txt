PHY TOOLS — DEDICATED SIMULATOR FIX

Root cause addressed:
The previous package launched tools inside an iframe srcdoc. The generic page loaded module scripts and dependent assets from that iframe context. This has been removed for built-in tools.

New flow:
- categories: index.html -> tools.html?unit=...
- generic tool: simulate.html?id=...&from=tools.html?unit=...
- Boyle's Law: boyles-with-sound.html?from=...

Runtime resilience:
- simulator UI/calculation module is initialized before the 3D engine is imported dynamically.
- if the 3D dependency/WebGL fails, the controls and calculations still initialize and a clear message is displayed.

Validation performed:
- catalog JSON parses: 10 units, 130 tools
- embedded catalog in index/tools matches data/catalog.json IDs
- every tool has title/description and Sinhala translations for title, description, unit, labels, result, formula, observation
- every catalog visualType has an engine buildModel branch
- all JavaScript syntax checks
- standalone page contains data-loader, import map, tool CSS, controls, graph and return URL handler
- every tool id maps to a dedicated simulate.html URL except Boyle's Law which uses its own page
- ZIP integrity check

Not claimed: all 130 models were individually browser-run with real CDN/WebGL. This execution environment blocks local browser HTTP access and internet DNS, so live 3D browser verification cannot be honestly claimed here.
